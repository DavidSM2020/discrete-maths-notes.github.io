Topic 04

Relations & Functions

A relation is any subset of a Cartesian product — an arbitrary set of allowable input–output pairs. A function is the well-behaved special case: every input has exactly one output. This topic develops the vocabulary of relations, the properties that make them useful, and then the classification, combination and reversal of functions.

Cartesian products

Definition · Cartesian product

The Cartesian product of sets \(A\) and \(B\) is the set of all ordered pairs with first coordinate from \(A\) and second coordinate from \(B\):

\[ A \times B = \{(a,b) \mid a \in A,\ b \in B\}. \]

Two different orderings are at work here, and they must not be confused:

  • Within a pair, order matters. \((a,b) \neq (b,a)\) unless \(a=b\).
  • Between pairs, order does not matter, because \(A \times B\) is a set: \(\{(a,b),(c,d)\} = \{(c,d),(a,b)\}\).
Theorem · size of a Cartesian product

\[ |A \times B| = |A| \cdot |B|. \]

Each of the \(|A|\) choices for the first coordinate pairs with each of the \(|B|\) choices for the second.

Example

Let \(A=\{0,1,2,3\}\) and \(B=\{0,1,4\}\). Then

\[ \begin{aligned} A \times B = \{&(0,0),(0,1),(0,4),\\ &(1,0),(1,1),(1,4),\\ &(2,0),(2,1),(2,4),\\ &(3,0),(3,1),(3,4)\}. \end{aligned} \]

There are \(4 \cdot 3 = 12\) pairs.

Why this matters

The Cartesian product is the raw material for everything in this topic. A relation is a chosen subset of \(A \times B\); a function is a relation with an extra restriction. The plane \(\mathbb{R}^2 = \mathbb{R} \times \mathbb{R}\) is the Cartesian product you already know from graphing.

Relations

Definition · Relation

Given sets \(A\) and \(B\), any subset of \(A \times B\) is called a relation from \(A\) to \(B\). We write \(R \subseteq A \times B\), and \((a,b) \in R\) means “\(a\) is related to \(b\)”.

A relation from \(A\) to \(A\) is called a relation on \(A\).

So a relation has no built-in rule. Any collection of pairs is allowed — including the empty set and the whole Cartesian product.

Example · the divides relation

Let \(A=\{2,3,5,6\}\) and define \(R\) on \(A\) by \((a,b) \in R\) iff \(a\) divides evenly into \(b\). Then

\[ R = \{(2,2),(3,3),(5,5),(6,6),(2,6),(3,6)\}. \]

The pair \((2,6)\) is in because \(2 \mid 6\); the pair \((6,2)\) is not.

Definition · Divides

For integers \(a,b\), “\(a\) divides \(b\)” is written \(a \mid b\) and means there exists an integer \(k\) with \(ak=b\).

Warning: \(a \mid b\) is a statement (true or false), whereas \(a/b\) is a number. The symbol \(\mid\) is also used for “such that” in set-builder notation; the context normally disambiguates, and many authors use a colon in set-builder notation to avoid the clash.

Example · different relations on the same sets

With \(A=\{0,1,2,3\}\) and \(B=\{0,1,4\}\), all of the following are relations from \(A\) to \(B\):

RelationRule it suggests
\(\{(0,0),(1,1),(2,4)\}\)\(x \mapsto x^2\), restricted to \(x < 3\)
\(\{(0,0),(1,1),(2,0),(3,1)\}\)\(x \mapsto x \bmod 2\)
\(\{(0,0),(1,0),(2,1),(3,1)\}\)“\(x\) is prime” indicator
\(\{(0,0),(1,4)\}\)No obvious rule — that is allowed
\(\varnothing\)The empty relation — a set, and a subset of everything

Counting relations

Theorem · number of relations

If \(|A|=m\) and \(|B|=n\), then there are

\[ 2^{mn} \]

distinct relations from \(A\) to \(B\).

The reason is a three-step argument worth reproducing in an exam:

  1. \(A \times B\) has \(mn\) elements.
  2. A relation is any subset of \(A \times B\).
  3. A set of size \(mn\) has \(2^{mn}\) subsets.
Example

For \(A=\{0,1,2,3\}\) and \(B=\{0,1,4\}\), there are \(2^{4 \cdot 3} = 2^{12} = 4096\) relations.

Relation vs power set

For a relation \(R\) from \(A\) to \(B\):

\[ R \subseteq A \times B \qquad\text{and}\qquad R \in \mathcal{P}(A \times B). \]

“Subset” and “element of the power set” say the same thing.

Source, target, domain, image

Draw the two sets side by side and draw an arrow from \(a\) to \(b\) whenever \((a,b) \in R\). Four pieces of vocabulary describe the picture.

Definition · Terminology

Let \(R\) be a relation from \(S\) to \(T\).

  • The source is \(S\), the set the relation leaves from.
  • The target is \(T\), the set the relation points to.
  • The domain is the subset of the source with at least one arrow out: \[ \mathrm{Dom}(R) = \{s \in S \mid \exists t \in T,\ (s,t) \in R\} \subseteq S. \]
  • The image is the subset of the target with at least one arrow in: \[ \mathrm{Im}(R) = \{t \in T \mid \exists s \in S,\ (s,t) \in R\} \subseteq T. \]
Example · “is less than”

Let \(A=\{1,3,5\}\), \(B=\{0,2,4,5\}\), and \((a,b) \in R\) iff \(a < b\). Then

\[ R = \{(1,2),(1,4),(1,5),(3,4),(3,5)\}. \]

  • Source \(= A\), target \(= B\).
  • \(\mathrm{Dom}(R) = \{1,3,5\} = A\) — every element of \(A\) has an arrow.
  • \(\mathrm{Im}(R) = \{2,4,5\}\) — the element \(0 \in B\) is never used.

Into and onto relations

Definition · Into and onto

Since \(\mathrm{Im}(R) \subseteq T\), there are exactly two possibilities:

  • Into: \(\mathrm{Im}(R) \subset T\) — the image is a proper subset of the target; at least one target element is unused.
  • Onto: \(\mathrm{Im}(R) = T\) — every target element receives at least one arrow.
Example

The “is less than” relation above is into, because \(0\) is not in the image.

The relation from \(A=\{-1,3,5\}\) to \(B=\{1,3,5\}\) defined by \(a < b\) is

\[ R=\{(-1,1),(-1,3),(-1,5),(3,5)\}, \]

whose image is \(\{1,3,5\}=B\), so it is onto.

Injective relations

Definition · Injective relation

A relation is injective (one-to-one) if there is at most one arrow into every element of the target.

Equivalently, no target element is hit twice.

Example

From \(A=\{-1,1,2\}\) to \(B=\{-1,1,4,8\}\):

  • The “is square root of” relation contains \((-1,1)\) and \((1,1)\), so target \(1\) has two incoming arrows. Not injective.
  • The “is cube root of” relation contains \((-1,-1)\), \((1,1)\), \((2,8)\) — each target is hit at most once. Injective.
Three independent questions

“Domain”, “onto” and “injective” answer different questions:

  • Domain: does every source element have an arrow out?
  • Onto: does every target element have an arrow in?
  • Injective: does every target element have at most one arrow in?

A relation can be onto but not injective, injective but not onto, both, or neither.

Relations on a set

When source and target are the same set \(A\), a relation can be applied repeatedly: output of one step becomes input to the next. This is the setting for the five standard properties.

iteration.txtabstract
A --R--> A --R--> A --R--> A --R--> ...

This repeated-application view underlies fixed-point methods, chaining, hashing, and state machines.

Reflexive and irreflexive

Definition · Reflexive

A relation \(R\) on \(A\) is reflexive iff every element is related to itself:

\[ (a,a) \in R \quad \forall a \in A. \]

Reflexive examples on \(\mathbb{Z}^+\)

“divides”: \(a \mid a\) always.
“less than or equal to”: \(a \le a\) always.
“has the same surname as”.

Not reflexive

“less than”: \((5,5) \notin R\).
“is half of”: \((3,3) \notin R\).
“is a parent of”.

Definition · Irreflexive

\(R\) is irreflexive (or irreflective) iff no element is related to itself:

\[ (a,a) \notin R \quad \forall a \in A. \]

Reflexive vs not reflexive

“Not reflexive” and “irreflexive” are different. A relation is not reflexive if it misses at least one diagonal pair; it is irreflexive if it misses all of them. A relation can be neither: for example \(R=\{(1,1),(1,2)\}\) on \(\{1,2\}\) has one diagonal pair but not both.

Symmetric and antisymmetric

Definition · Symmetric

\(R\) is symmetric iff

\[ (a_1,a_2) \in R \;\Rightarrow\; (a_2,a_1) \in R \quad \forall a_1,a_2 \in A. \]

Every arrow has a matching arrow in the opposite direction.

Definition · Antisymmetric

\(R\) is antisymmetric iff

\[ (a_1,a_2) \in R \ \land\ (a_2,a_1) \in R \;\Rightarrow\; a_1=a_2 \quad \forall a_1,a_2 \in A. \]

Two distinct elements cannot point at each other.

They are not opposites

A relation may be symmetric, antisymmetric, both, or neither:

  • “\(=\)” is both symmetric and antisymmetric.
  • “\(\le\)” is antisymmetric but not symmetric.
  • “has the same surname” is symmetric but not antisymmetric.
  • “divides” on \(\mathbb{Z}^+\) is antisymmetric but not symmetric.

“Not symmetric” does not mean antisymmetric.

Proof strategy for antisymmetry

Assume \((a_1,a_2) \in R\) and \((a_2,a_1) \in R\) with \(a_1 \neq a_2\), then derive a contradiction. Alternatively, prove directly that the two conditions force \(a_1=a_2\).

Example · the unit circle relation

Let \(R=\{(x,y) \in \mathbb{R}^2 \mid x^2+y^2=1\}\).

  • Reflexive? No: \((2,2) \notin R\) since \(2^2+2^2=8 \neq 1\).
  • Symmetric? Yes: \(x^2+y^2 = y^2+x^2\), so \((x,y)\in R \Rightarrow (y,x)\in R\).
  • Antisymmetric? No: \((0,1)\in R\) and \((1,0)\in R\), but \(0 \neq 1\).

Transitive

Definition · Transitive

\(R\) is transitive iff

\[ (a_1,a_2) \in R \ \land\ (a_2,a_3) \in R \;\Rightarrow\; (a_1,a_3) \in R \quad \forall a_1,a_2,a_3 \in A. \]

A two-step path can always be short-circuited into a one-step arrow.

“Less than”, “greater than”, “equals”, “divides”, “is an ancestor of” and “is a subset of” are all transitive. “Is a parent of” is not: a parent of a parent is a grandparent, not a parent.

Example · a relation that is reflexive and symmetric but not transitive

On the set of all people, let \((x,y) \in R\) iff \(x\) and \(y\) have at least one biological parent in common.

  • Reflexive: everyone shares a parent with themselves.
  • Symmetric: sharing is mutual.
  • Not transitive: Larry and Curly might share a parent, and Curly and Mo might share a (different) parent, while Larry and Mo share none.

Equivalence relations and classes

Definition · Equivalence relation

A relation \(R\) on \(A\) is an equivalence relation iff it is

  1. reflexive,
  2. symmetric,
  3. transitive.
Definition · Equivalence classes

An equivalence relation partitions \(A\) into equivalence classes \(A_1,A_2,\ldots\), where two elements are in the same class iff they are related. The classes are:

  • disjoint: \(A_i \cap A_j = \varnothing\) when \(i \neq j\);
  • exhaustive: \(A_1 \cup A_2 \cup \cdots = A\).
Example · same surname

On the set of all people in Ireland, let \((x,y) \in R\) iff \(x\) and \(y\) have the same surname. This is reflexive, symmetric and transitive, hence an equivalence relation. The equivalence classes are the groups of people sharing each surname.

Example · congruence modulo 2

On \(\mathbb{Z}\), let \((a,b) \in R\) iff \(a\) and \(b\) have the same remainder on division by 2. The equivalence classes are the even integers and the odd integers — disjoint and exhaustive.

Equality

On \(\mathbb{Z}\), \((a,b)\in R\) iff \(a=b\). Classes are singletons.

Same length

On strings, classes are strings of length 0, length 1, length 2, …

Same remainder

Modulo \(n\), there are exactly \(n\) equivalence classes.

Definition · Asymmetric

\(R\) is asymmetric iff

\[ (a_1,a_2) \in R \;\Rightarrow\; (a_2,a_1) \notin R \quad \forall a_1,a_2 \in A. \]

No pair points both ways, not even an element to itself.

Lemma

A relation is asymmetric iff it is both irreflexive and antisymmetric.

Digraphs

For a relation on a finite set, a directed graph (digraph) is the clearest picture. Draw each element of \(A\) as a vertex; draw a directed edge \(a \to b\) whenever \((a,b) \in R\). Layout and edge shape are irrelevant — only which vertices point to which.

PropertyDigraph signature
ReflexiveA self-loop at every vertex.
IrreflexiveNo self-loops.
SymmetricEvery edge has a matching reverse edge (bidirectional pairs).
AntisymmetricNo pair of distinct vertices has edges in both directions (self-loops ignored).
TransitiveFor every path \(x \to y \to z\), there is a direct edge \(x \to z\).
AsymmetricNo edge in either direction for any pair of vertices, including no self-loops.
Example · read the picture

On \(A=\{a,b,c,d\}\), let

\[ R=\{(a,b),(b,c),(c,b)\}. \]

PropertyVerdictReason
ReflexiveNoNo self-loops.
IrreflexiveYesEvery vertex lacks a self-loop.
SymmetricNo\(a \to b\) has no reverse \(b \to a\).
AntisymmetricNo\(b \to c\) and \(c \to b\) with \(b \neq c\).
TransitiveNo\(b \to c\) and \(c \to b\) require \(b \to b\), which is absent.
AsymmetricNo\(b \to c\) has a reverse.

Closures

Definition · Closure

For a property \(X\), the \(X\)-closure of \(R\) is the smallest superset of \(R\) that has property \(X\). “Smallest” means you add only what is forced.

ClosureHow to build it
Reflexive closureAdd \((a,a)\) for every \(a \in A\) that lacks it.
Symmetric closureFor every \((a_1,a_2) \in R\), add \((a_2,a_1)\) if absent.
Transitive closureRepeatedly add \((a_1,a_3)\) whenever \((a_1,a_2)\) and \((a_2,a_3)\) are present, until no new pairs appear.
Example

Let \(R=\{(1,2),(2,3)\}\) on \(A=\{1,2,3\}\).

  • Reflexive closure: \(R \cup \{(1,1),(2,2),(3,3)\}\).
  • Symmetric closure: \(R \cup \{(2,1),(3,2)\}\).
  • Transitive closure: add \((1,3)\); the result is \(\{(1,2),(2,3),(1,3)\}\).
Closure algorithm

Repeat the one-step rule until the set stops changing. Because \(A\) is finite, this terminates: each pass either adds a pair or stabilises, and there are at most \(|A|^2\) pairs.

Powers of relations

Definition · Power of a relation

For a relation \(R\) on \(A\), define

\[ R^0 = I_A = \{(a,a) \mid a \in A\}, \qquad R^n = R^{n-1} \circ R \ \text{ for } n \ge 1. \]

Here \(S \circ R\) means “apply \(R\), then apply \(S\)”. So \(R^n\) consists of all pairs connected by a path of exactly \(n\) \(R\)-steps.

Example

Let \(R=\{(1,2),(2,3)\}\) on \(\{1,2,3\}\). Then

\[ R^2 = \{(1,3)\}, \qquad R^3 = \varnothing. \]

There is a 2-step path \(1 \to 2 \to 3\), but no 3-step path.

Link to transitive closure

The transitive closure of \(R\) is

\[ R \cup R^2 \cup R^3 \cup \cdots \]

— all pairs reachable by a path of length at least one. On a finite set the union stops growing after at most \(|A|\) powers.

Functions as relations

A function is a relation that behaves like a deterministic program: every input produces exactly one output.

Definition · Function

A relation \(R\) from \(A\) to \(B\) is a function from \(A\) to \(B\) iff

  1. every element of \(A\) is in the domain — at least one arrow leaves each input;
  2. no element of \(A\) has more than one output — if \((a,b) \in R\) and \((a,c) \in R\), then \(b=c\).

In symbols: \(\mathrm{Dom}(R)=A\) and \((a,b),(a,c)\in R \Rightarrow b=c\).

Why both conditions?

The relation \(a=b^2\) on \(\mathbb{R}\) fails both: \(16\) maps to \(4\) and \(-4\), while \(-1\) maps to nothing. A function must fix both problems.

Programmer's view

One input, one return value. Python can return None or a tuple to fake the other cases, but that is a workaround, not a mathematical function.

Example · set of ordered pairs

Let \(S=\{1,2,3\}\) and \(T=\{a,b,c\}\). Then

\[ f=\{(1,a),(2,a),(3,b)\} \]

is a function: every element of \(S\) appears exactly once as a first coordinate. The image is \(\{a,b\}\), so \(f\) is into (not onto).

By contrast, \(\{(1,a),(1,b),(2,c)\}\) is not a function (\(1\) has two outputs), and \(\{(1,a),(3,c)\}\) is not a function from \(S\) (\(2\) has none).

Example · lookup table

A lookup table is a function written as rows. Memory is sometimes cheaper than computation: prime tables, ASCII and Unicode tables work this way.

inputoutput
1a
2a
3b

The domain is the set of inputs \(\{1,2,3\}\); the image is the set of outputs \(\{a,b\}\).

Function notation and well-definedness

The full specification of a function has three parts:

\[ \underbrace{f}_{\text{name}} : \underbrace{A}_{\text{source / domain}} \to \underbrace{B}_{\text{target}} : \underbrace{x \mapsto f(x)}_{\text{rule}} \]

All of the following are used for the same function, with decreasing formality:

\[ f = \{(a,b) \mid a \in \mathbb{R},\ b \in \mathbb{R},\ b=3a\} \]
\[ f : \mathbb{R} \to \mathbb{R} : x \mapsto 3x \qquad\text{or}\qquad f : \mathbb{R} \to \mathbb{R} : f(x)=3x \]
\[ f : x \mapsto 3x \qquad\text{or}\qquad f(x)=3x \qquad\text{or}\qquad f=3x \]
Well-definedness

If only the rule is given, you must choose the largest domain on which it makes sense. For example, assuming \(\mathbb{R} \to \mathbb{R}\):

RuleCorrect formal definitionReason
\(x^2\)\(a : \mathbb{R} \to \mathbb{R} : x \mapsto x^2\)No restriction.
\(\sqrt{x}\)\(b : [0,\infty) \to \mathbb{R} : x \mapsto \sqrt{x}\)Cannot square-root a negative real.
\(\dfrac{1}{x-2}\)\(c : \mathbb{R} \setminus \{2\} \to \mathbb{R} : x \mapsto \dfrac{1}{x-2}\)Cannot divide by zero.
\(\log x\)\(d : (0,\infty) \to \mathbb{R} : x \mapsto \log x\)Logarithm needs a positive input.

On the integers the restrictions differ, because the square root of a non-square integer is not an integer.

Interval notation

Round brackets exclude an endpoint; square brackets include it. On \(\mathbb{R}\):

IntervalSetDescription
\([a,b]\)\(\{x \in \mathbb{R} : a \le x \le b\}\)Closed, finite
\((a,b)\)\(\{x \in \mathbb{R} : a < x < b\}\)Open, finite
\([a,b)\)\(\{x \in \mathbb{R} : a \le x < b\}\)Semi-open, finite
\((a,b]\)\(\{x \in \mathbb{R} : a < x \le b\}\)Semi-open, finite
\([a,\infty)\)\(\{x \in \mathbb{R} : a \le x < \infty\}\)Semi-open, infinite
\((a,\infty)\)\(\{x \in \mathbb{R} : a < x < \infty\}\)Open, infinite
\((-\infty,b]\)\(\{x \in \mathbb{R} : -\infty < x \le b\}\)Semi-open, infinite
\((-\infty,b)\)\(\{x \in \mathbb{R} : -\infty < x < b\}\)Open, infinite
\((-\infty,\infty)\)\(\mathbb{R}\)The real line
Programming connection

Python's range(a, b) is the integer interval \([a,b)\): the start is included, the stop is excluded. This is why range(0, 5) yields \(0,1,2,3,4\) — five values, not six. The same semi-open convention is used in slicing.

Surjective functions

Definition · Surjective (onto)

A function \(f : A \to B\) is surjective (onto) iff its image equals its target:

\[ \forall b \in B\ \exists a \in A\ [f(a)=b]. \]

Every element of \(B\) is hit by at least one arrow. If the image is a proper subset of the target, the function is into (not surjective).

Example · checking surjectivity
  • \(f : \mathbb{R} \to \mathbb{R},\ f(x)=3x+1\): surjective. Given \(b \in \mathbb{R}\), take \(a=(b-1)/3\).
  • \(f : \mathbb{N} \to \mathbb{N},\ f(x)=3x+1\): not surjective. The value \(0 \in \mathbb{N}\) is never produced (and neither is \(1\), \(2\), \(4\), …).
  • \(f : \mathbb{N} \to \mathbb{N},\ f(m)=2m\): not surjective. Odd numbers are never outputs.
Why it matters

If a function is surjective, every target value can be generated from some input. If it is not, at least one value is unreachable no matter what you feed in — the basis of plausibly deniable encryption.

Injective functions

Definition · Injective (one-to-one)

A function \(f : A \to B\) is injective iff

\[ f(a_1)=f(a_2) \;\Rightarrow\; a_1=a_2 \quad \forall a_1,a_2 \in A. \]

Equivalently, by contrapositive:

\[ a_1 \neq a_2 \;\Rightarrow\; f(a_1) \neq f(a_2). \]

Different inputs give different outputs; each target element receives at most one arrow.

Proof template

To prove injective: assume \(f(a_1)=f(a_2)\) and manipulate until \(a_1=a_2\). To disprove: exhibit two distinct inputs with the same output.

Example · checking injectivity
  • \(f : \mathbb{R} \to \mathbb{R},\ f(x)=3x+1\): injective, since \(3a_1+1=3a_2+1 \Rightarrow a_1=a_2\).
  • \(f : \mathbb{N} \to \mathbb{N},\ f(m)=2m\): injective, since \(2a_1=2a_2 \Rightarrow a_1=a_2\).
  • \(g : \mathbb{Z} \to \mathbb{Z},\ g(m)=2m^2-7\): not injective, since \(g(1)=g(-1)=-5\) but \(1 \neq -1\).
  • \(f : \mathbb{R} \to \mathbb{R},\ f(x)=x^2\): not injective, since \(f(2)=f(-2)=4\).

Bijective functions

Definition · Bijective

\(f : A \to B\) is bijective (a bijection) iff it is both injective and surjective. In the arrow picture: exactly one arrow leaves every source element, and exactly one arrow enters every target element.

Theorem · bijections are reversible

A function has an inverse if and only if it is bijective. Bijections pair up the elements of \(A\) and \(B\) one-for-one, so \(|A|=|B|\) for finite sets.

Example · classification table
FunctionInjective?Surjective?Bijective?
\(f : \mathbb{R} \to \mathbb{R},\ x \mapsto 3x+1\)YesYesYes
\(f : \mathbb{N} \to \mathbb{N},\ x \mapsto 3x+1\)YesNoNo
\(f : \mathbb{Q} \to \mathbb{Q},\ x \mapsto 3x+1\)YesYesYes
\(f : \mathbb{N} \to \mathbb{N},\ m \mapsto 2m\)YesNoNo
\(f : \mathbb{R} \to \mathbb{R},\ m \mapsto 2m\)YesYesYes
\(g : \mathbb{Z} \to \mathbb{Z},\ m \mapsto 2m^2-7\)NoNoNo

The domain and target are part of the function. The same rule can be bijective over \(\mathbb{R}\) and fail to be surjective over \(\mathbb{N}\).

Cardinality check

For finite sets, if \(|A|=|B|\), then a function is injective iff it is surjective iff it is bijective. If \(|A| \neq |B|\), no bijection can exist. Use this as a fast sanity check before doing algebra.

Function equality and arithmetic

Definition · Function equality

Two functions \(f\) and \(g\) are equal iff they have the same domain and the same value everywhere on it:

\[ f=g \iff \mathrm{Dom}(f)=\mathrm{Dom}(g) \ \land\ f(x)=g(x)\ \forall x \in \mathrm{Dom}(f). \]

Example · same rule, different domain

\[ f : \mathbb{Z} \to \mathbb{Z} : x \mapsto x^2 \qquad\text{and}\qquad g : \mathbb{R} \to \mathbb{R} : x \mapsto x^2 \]

are not equal, because their domains differ, even though the formula is identical.

Example · different rules, same function

On \(A=\{-1,0,1,2\}\) with target \(\{0,1,2\}\),

\[ h : x \mapsto |x| \qquad\text{and}\qquad k : x \mapsto -\frac{x^3}{3}+x^2+\frac{x}{3} \]

are equal. Both give the values \(1,0,1,2\) on \(-1,0,1,2\). A function is determined by its input–output behaviour, not by how the formula is written.

Definition · Pointwise arithmetic

Given functions \(f\) and \(g\) with a common domain:

\[ \begin{aligned} (f+g)(x) &= f(x)+g(x),\\ (f-g)(x) &= f(x)-g(x),\\ (fg)(x) &= f(x)g(x),\\ (f/g)(x) &= f(x)/g(x), \quad g(x) \neq 0. \end{aligned} \]

The domain of the quotient excludes every \(x\) with \(g(x)=0\).

Example

Let \(f(x)=x^4-16\) and \(g(x)=|x|-4\). Then

  • \((f+g)(2)=f(2)+g(2)=0+(-2)=-2\).
  • \((fg)(2)=0 \cdot (-2)=0\).
  • \((f/g)(2)=0/(-2)=0\).
  • \((g/f)(2)=(-2)/0\) is undefined, so \(2 \notin \mathrm{Dom}(g/f)\).
  • \((g/f)(1)=(-3)/(-15)=\tfrac15\).

Composition

Definition · Composition

Let \(f : A \to B\) and \(g : B \to C\). The composition of \(f\) followed by \(g\) is

\[ g \circ f : A \to C, \qquad (g \circ f)(x)=g(f(x)). \]

Read “\(g\) after \(f\)”. The output type of \(f\) must match the input type of \(g\), otherwise the composition is undefined.

Example · pairs

With \(f=\{(1,a),(2,a),(3,b)\}\) and \(g=\{(a,B),(b,C),(c,A)\}\):

\[ g \circ f = \{(1,B),(2,B),(3,C)\}. \]

Example · formulae

Let \(f(x)=x^3\) and \(g(x)=3x+1\). Then

\[ (g \circ f)(x)=g(x^3)=3x^3+1, \]

whereas

\[ (f \circ g)(x)=f(3x+1)=(3x+1)^3=27x^3+27x^2+9x+1. \]

So \(f \circ g \neq g \circ f\) in general. Composition is not commutative.

Theorem · composition is associative

For \(f : A \to B\), \(g : B \to C\), \(h : C \to D\),

\[ h \circ (g \circ f) = (h \circ g) \circ f. \]

Grouping does not matter; the value on \(x\) is always \(h(g(f(x)))\).

Definition · Powers of a function

For \(f : A \to A\):

\[ f^1=f, \qquad f^{n+1}=f \circ f^n \ \text{ for } n \ge 1. \]

That is, \(f^{n+1}(a)=f(f^n(a))\). Note carefully: \(f^2(x)\) means \(f(f(x))\), not \((f(x))^2\).

Inverses

Definition · Inverse

Let \(f : A \to B\). If there exists a function \(g : B \to A\) such that

\[ (g \circ f)(x)=x \ \forall x \in A \qquad\text{and}\qquad (f \circ g)(y)=y \ \forall y \in B, \]

then \(g\) is the inverse of \(f\), written \(f^{-1}\).

Both directions are required: one composition returning the identity on one side is not enough. If the inverse exists it is unique, and it “undoes” \(f\): if \(f(a)=b\), then \(f^{-1}(b)=a\).

Theorem · existence criterion

\(f^{-1}\) exists iff \(f\) is bijective (injective and surjective).

  • Injectivity makes the reverse assignment unambiguous.
  • Surjectivity makes it defined on all of \(B\).
Example · a non-obvious inverse pair

On \(A=\{0,1,2,3,4\}\), let

\[ f(x)=-\frac{5}{6}x^4+\frac{20}{3}x^3-\frac{50}{3}x^2+\frac{83}{6}x \qquad\text{and}\qquad g(x)=2x \bmod 5. \]

The values are:

\(x\)01234
\(f(x)\)03142
\(g(f(x))\)01234

So \(g \circ f = I_A\) and \(f \circ g = I_A\): the two functions are inverses.

Existence is not efficiency

Knowing that \(f^{-1}\) exists says nothing about how hard it is to compute. Public-key cryptography is built on bijections whose inverses are believed to be computationally infeasible without a secret key.

Exercise · find the inverse

Let \(f : \mathbb{R} \to \mathbb{R}\), \(f(x)=3x+1\). Solve \(y=3x+1\) for \(x\):

\[ x=\frac{y-1}{3}, \qquad\text{so}\qquad f^{-1}(y)=\frac{y-1}{3}. \]

Check: \(f^{-1}(f(x)) = \frac{(3x+1)-1}{3}=x\), and \(f(f^{-1}(y))=3\cdot\frac{y-1}{3}+1=y\).

The Caesar cipher

The Caesar (shift) cipher is the classic application of inverse functions. Identify the letters with the integers \(0,\ldots,25\): \(A \leftrightarrow 0\), \(B \leftrightarrow 1\), …, \(Z \leftrightarrow 25\). For a shift \(n\),

\[ E_n(x)=(x+n) \bmod 26, \qquad D_n(x)=(x-n) \bmod 26. \]

These are inverse functions: \(D_n(E_n(x)) = (x+n-n) \bmod 26 = x\). Both are bijections on the set of letters, which is exactly why decryption is always possible.

Example · shift 3

Caesar used \(n=3\). Encrypting ATTACK AT DAWN:

PlainATTACKATDAWN
CipherDWWDFNDWGDZQ

So the ciphertext is DWWDFN DW GDZQ.

Decrypting V HQG PRUH IRRG with \(n=3\) gives SEND MORE FOOD.

caesar.pypython
def shift(n, x):
    return (x + n) % 26

def encrypt(n, message):
    result = ""
    for c in message:
        if 'A' <= c <= 'Z':
            result += chr(shift(n, ord(c) - ord('A')) + ord('A'))
        else:
            result += c
    return result

def decrypt(n, message):
    return encrypt(26 - n, message)

plaintext = "ATTACK AT DAWN"
cyphertext = encrypt(3, plaintext)
test = decrypt(3, cyphertext)

print("Plaintext =", plaintext)     # ATTACK AT DAWN
print("Cyphertext =", cyphertext)   # DWWDFN DW GDZQ
print("test =", test)               # ATTACK AT DAWN
ROT13

ROT13 is the Caesar cipher with \(n=13\). Since \(13+13=26 \equiv 0 \pmod{26}\), encryption and decryption are the same operation — a self-inverse function.

Library of functions

Discrete mathematics focuses on finite and countable domains, but the standard functions over \(\mathbb{R}\) reappear constantly in computing: polynomial running times, logarithmic complexity, exponential growth, and trigonometric transforms in graphics. Here is the short catalogue.

Absolute value

Definition · Absolute value

\[ |x| = \sqrt{x^2} = \begin{cases} -x, & x < 0,\\ x, & x \ge 0. \end{cases} \]

Properties:

  • \(|x| \ge 0\);
  • \(|x|=0 \iff x=0\);
  • \(|xy|=|x||y|\);
  • \(|x+y| \le |x|+|y|\) (triangle inequality).

It measures distance: \(|x-c|=a\) is the set of points exactly \(a\) units from \(c\).

Signum

Definition · Signum

\[ \operatorname{sgn}(x) = \begin{cases} -1, & x < 0,\\ 0, & x=0,\\ 1, & x > 0. \end{cases} \]

Equivalently, \(\operatorname{sgn}(x)=|x|/x\) for \(x \neq 0\), and \(\operatorname{sgn}(0)=0\). Some authors leave \(\operatorname{sgn}(0)\) undefined; both conventions are fine provided everyone knows which is in use.

Heaviside

Definition · Heaviside step

\[ H(x) = \begin{cases} 0, & x < 0,\\ 1, & x \ge 0. \end{cases} \]

It models a switch that turns on at \(x=0\). This is the right-continuous version; some texts set \(H(0)=\tfrac12\).

Floor and ceiling

Definition · Floor and ceiling
  • \(\lfloor x \rfloor\) is the greatest integer \(\le x\).
  • \(\lceil x \rceil\) is the least integer \(\ge x\).

Examples: \(\lfloor 2.7 \rfloor = 2\), \(\lceil 2.1 \rceil = 3\), \(\lfloor -1.2 \rfloor = -2\), \(\lceil -1.2 \rceil = -1\).

The graph of \(y=\lfloor x \rfloor\) is a staircase: constant on every interval \([n,n+1)\), with a jump at each integer. A solid dot marks an included endpoint and an empty dot an excluded one.

Floor of negatives

Floor always moves left on the number line, ceiling always moves right. For negative numbers this is not the same as truncation: \(\lfloor -1.2 \rfloor = -2\), not \(-1\).

Power functions

Definition · Power function

A function of the form

\[ f : (0,\infty) \to (0,\infty) : x \mapsto x^a, \qquad a \in \mathbb{R}, \]

is a power function. The domain may extend depending on \(a\):

  • If \(a \in \mathbb{N} \setminus \{0\}\), the domain is \(\mathbb{R}\) (e.g. \(x, x^2, x^3\)).
  • If \(a\) is a negative integer, the domain is \(\mathbb{R} \setminus \{0\}\).
  • If \(a\) has an odd denominator in lowest terms, negative inputs may be allowed; for even denominators they are not.

Polynomials

Definition · Polynomial

A polynomial of degree \(n\) is a function of the form

\[ f(x)=a_nx^n+a_{n-1}x^{n-1}+\cdots+a_1x+a_0, \qquad a_k \in \mathbb{R},\ a_n \neq 0. \]

Properties of polynomials
  1. A degree-\(n\) polynomial has at most \(n\) real roots and at most \(n-1\) local minima/maxima.
  2. For large \(|x|\), behaviour is controlled by the leading term \(a_nx^n\).
  3. Near zero, behaviour is controlled by the lowest non-zero term.

Polynomials are easy to evaluate, easy to implement, and can approximate any finite smooth curve — hence their importance in computing.

DegreeFormName and key facts
0\(f(x)=c\)Constant; horizontal line.
1\(f(x)=mx+c\)Affine (linear); slope \(m\), intercept \(c\); one root at \(x=-c/m\).
2\(f(x)=ax^2+bx+c\)Quadratic; parabola; roots \(\dfrac{-b \pm \sqrt{b^2-4ac}}{2a}\).
3\(f(x)=ax^3+bx^2+cx+d\)Cubic; up to three roots and two turning points.

For a quadratic, the canonical (completed-square) form is

\[ f(x)=a\left(x+\frac{b}{2a}\right)^2-\frac{b^2-4ac}{4a}, \]

which locates the vertex and the range. The discriminant \(b^2-4ac\) decides the number of real roots: negative means none, zero means one repeated root, positive means two.

Graphs on the Cartesian plane

There are three graphical representations of a relation or function, each suited to a different setting:

Venn diagram

Two sets with arrows. Best for discrete, finite relations where you care about domain and image.

Digraph

Vertices and directed edges. Only when source = target. Best for reflexivity, symmetry, transitivity.

2D Cartesian graph

Points \((x,f(x))\) in the plane. Best for continuous or infinite sets; essential in calculus.

Example · finite set

On \(A=\{-1,0,1,2\}\), let \(f(x)=-\frac{x^3}{3}+x^2+\frac{x}{3}\). The values are \(f(-1)=1\), \(f(0)=0\), \(f(1)=1\), \(f(2)=2\). All four representations — lookup table, Venn diagram, digraph, and four plotted points — describe the same function

\[ f=\{(-1,1),(0,0),(1,1),(2,2)\}. \]

Example · discrete infinite set

On \(A=\mathbb{N}\setminus\{0\}\), let \(f(x)\) be the number of factors of \(x\). The values begin \(1,2,2,3,2,4,\ldots\). The Cartesian plot shows a spike exactly at each prime — primes have two factors. Any finite drawing is only a sample of an infinite set.

Example · continuous set

On \(\mathbb{R}\), the floor function \(f(x)=\lfloor x \rfloor\) produces a staircase with jumps of 1 at every integer. The horizontal segments lie at integer heights, and the endpoints alternate open/closed.

Vertical line test

A relation on \(\mathbb{R}\) is a function iff every vertical line meets its graph at most once. A failure means one input has two outputs. This is the graphical version of the “at most one arrow leaving each input” condition.

Relations and functions in Python

A relation is naturally a set of tuples; a finite function is a dictionary or a set of pairs. The comprehensions below are direct translations of the definitions.

relations.pypython
A = {0, 1, 2, 3}
B = {0, 1, 4}

# Cartesian product
C = {(a, b) for a in A for b in B}
print(len(C))               # 12

# A relation: "b is a times something", e.g. b = 4a
R = {(a, b) for a in A for b in B if b == 4 * a}
print(R)                    # {(0, 0), (1, 4)}

# Domain and image
domain = {a for (a, b) in R}
image  = {b for (a, b) in R}
print(domain, image)        # {0, 1} {0, 4}

# Is R a function from A to B? Every input exactly once.
def is_function(R, A):
    firsts = [a for (a, b) in R]
    return set(firsts) == set(A) and len(firsts) == len(set(firsts))

print(is_function(R, A))    # False: 2 and 3 have no output
properties.pypython
def reflexive(R, A):
    return all((a, a) in R for a in A)

def symmetric(R):
    return all((b, a) in R for (a, b) in R)

def antisymmetric(R):
    return all(a == b for (a, b) in R if (b, a) in R)

def transitive(R):
    return all((a, c) in R for (a, b) in R for (b2, c) in R if b == b2)

def irreflexive(R, A):
    return all((a, a) not in R for a in A)

A = {1, 2, 3}
R = {(1, 1), (1, 2), (2, 1), (2, 2), (3, 3)}

print(reflexive(R, A))      # True
print(symmetric(R))         # True
print(antisymmetric(R))     # False: (1, 2) and (2, 1) with 1 != 2
print(transitive(R))        # True
print(irreflexive(R, A))    # False
functions.pypython
# A finite function as a dictionary
f = {1: "a", 2: "a", 3: "b"}

print(f[1])                         # a
print(set(f.keys()))                # domain {1, 2, 3}
print(set(f.values()))              # image  {'a', 'b'}

# Composition of two finite functions
g = {"a": 10, "b": 20}
go_f = {x: g[f[x]] for x in f if f[x] in g}
print(go_f)                         # {1: 10, 2: 10, 3: 20}

# A function defined by a rule
def square(x):
    return x * x

print(square(-3))                   # 9
print([square(x) for x in range(5)])  # [0, 1, 4, 9, 16]
Dictionary keys

Python dictionary keys must be hashable, so a function whose domain contains lists cannot be stored directly as a dict. Use tuples instead: f[(1, 2)] = 3. Also remember that a Python function is not automatically total: calling it outside its intended domain may raise an exception rather than return a value.

Exam checklist

Must be able to

  • Form a Cartesian product and count its elements.
  • State the definition of a relation and give examples as sets of pairs.
  • Compute \(2^{|A||B|}\), the number of relations.
  • Find the domain and image of a relation.
  • Decide into/onto and injective/not injective from a diagram or a set of pairs.
  • Test reflexivity, symmetry, antisymmetry, transitivity, irreflexivity and asymmetry.
  • Recognise an equivalence relation and list its equivalence classes.
  • Read the five properties off a digraph.
  • Construct reflexive, symmetric and transitive closures.
  • Compute powers of a relation and link them to the transitive closure.
  • Decide whether a relation is a function.
  • Determine a correct domain from a rule.
  • Classify functions as injective, surjective, bijective — and justify it.
  • Compute compositions and inverses.
  • Implement and decrypt a Caesar cipher.
  • Sketch the standard library functions and state their key properties.

Common traps

  • Confusing “relation” with “function”: every function is a relation, not conversely.
  • Using \(2^{|A|+|B|}\) instead of \(2^{|A||B|}\) for the number of relations.
  • Confusing image with target.
  • Thinking “not symmetric” means antisymmetric.
  • Thinking “not reflexive” means irreflexive.
  • Checking transitivity only on pairs that happen to be listed.
  • Forgetting the identity relation in \(R^0\).
  • Assuming \(f \circ g = g \circ f\).
  • Confusing \(f^{-1}(x)\) with \(1/f(x)\).
  • Writing \(f^2(x)\) for \((f(x))^2\).
  • Claiming a function is invertible without checking both injective and surjective.
  • Ignoring the domain when deciding equality or bijectivity.
  • Applying a rule outside its valid domain (division by zero, square roots of negatives).
Before you submit

For every relation question, write down the source and target first. For every function question, write the domain and target explicitly. For every property, write the definition with quantifiers before testing examples — most lost marks come from testing a few pairs and guessing.
