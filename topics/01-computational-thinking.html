Computational Thinking

The aim of the module is to learn to offload hard — or merely boring — computational tasks to computers. This topic starts that process: Python fundamentals first, then the standard code patterns used to implement the mathematics in the rest of the module.

What computational thinking means

Computational thinking is the skill of recognising when a problem is better solved by a machine, describing the solution precisely enough for a machine to execute it, and then translating that description into a programming language. You will not master it in one semester, but the module builds the foundations:

  • recognising repetition (loops) and choice (conditionals);
  • storing and organising data in collections;
  • packaging reusable logic into functions;
  • moving fluently between mathematical notation and Python.
Working definition

Computational thinking is the process of formulating a problem and its solution so that the solution can be carried out by a computer — including abstraction, decomposition, pattern recognition, and algorithm design.

Python fundamentals

A very brief history

  • Invented in the Netherlands in the early 1990s by Guido van Rossum.
  • Named after Monty Python, not the snake.
  • Designed to be scalable, object-oriented and functional from the beginning.
  • Python 3.0 was released in 2008 to fix design flaws in Python 2.
  • Today it is the dominant language for machine learning and data mining.

Data and data types

Every piece of data in Python is an object. Objects have attributes (data stored inside them) and methods (operations that act on them). Python determines the type automatically — unlike languages such as Processing or Java where you must declare it — and the type determines what operations are legal.

TypeMeaningExamples
NoneRepresents missing dataNone

Use type(x) to inspect the type of a value. A value can change type after an operation — for example, division always produces a float:

types.pypython
w = None
x = 4
y = '4'
z = 4.0

print(type(w), type(x), type(y), type(z))

x = x * 10
y = y * 10          # string repetition: '4' becomes '4444444444'
z = z * 10

print(type(w), type(x), type(y), type(z))

Notice that '4' * 10 repeats the string; it does not multiply numerically. This is why the type matters.

Collections: sets and lists

The module uses two collections constantly. The distinction is fundamental:

Set — unordered, distinct

A collection where order does not matter and duplicates are impossible. Written with braces in Python, but an empty set must be created with set() because {} is a dictionary.

List — ordered, repeatable

A sequence: positions matter (index starts at 0) and values may repeat. Ordered does not mean sorted; it means each element has a position.

collections_preview.pypython
# Sets
z = set()                 # empty set
a = {1, 3, 1, 2, 1, 5, 4} # duplicates ignored
b = {1, 'a', 3}

print(len(a))             # size of set
print(a & b)               # intersection
print(a | b)               # union
print(a - b)               # set difference
print(b - a)

# Lists
z = []                    # empty list
a = [1, 3, 1, 2, 1, 5, 4]
b = [1, 3]

print(len(a))
print(a + b)              # concatenation
print(a[2])               # zero-based indexing
print(a[2:5])             # slicing: semi-open [2, 5)
print(a[-4])              # negative indexing from the end

Looping: for and while

Use a for loop when you know how many times to repeat, or when you are iterating over a collection. Python's for is really a for-each loop. Use range to generate a sequence of integers; note that Python intervals are semi-open: range(5) gives \(0,1,2,3,4\).

loops.pypython
# for-each over a list
for letter in ['a', 'e', 'i', 'o', 'u']:
    print(letter, 'is a vowel')

# BEWARE: a set has no order, so the order of iteration is not guaranteed
for letter in {'a', 'e', 'i', 'o', 'u'}:
    print(letter, 'is a vowel')

# range builds an integer sequence: 0, 1, 2, 3, 4
for x in range(5):
    print(x)

# Use while when the number of repetitions is unknown
k = 0
while k < 5:
    print(k)
    k += 1
Why for-each is safer

A classic for loop in C/Java has an explicit counter and is prone to off-by-one errors. Python's for-each loop iterates over the values themselves, which removes most of that risk.

Making decisions: if, elif, else

Conditionals choose which block of code runs. Only the first matching branch executes.

fizz_buzz.pypython
# Multiples of 3 → "fuzz", multiples of 5 → "buzz",
# multiples of 15 → "fuzz buzz"
for k in range(1, 21):
    if k % 15 == 0:
        print("fuzz buzz")
    elif k % 3 == 0:
        print("fuzz")
    elif k % 5 == 0:
        print("buzz")
    else:
        print(k)

The order matters: test k % 15 == 0 before k % 3 == 0, otherwise multiples of 15 would print only "fuzz".

Functions: def and return

A function is a named block of code that runs only when called. Data goes in through parameters and comes back through return.

functions.pypython
def add(num1, num2):
    print("Number 1", num1)
    print("Number 2", num2)
    result = num1 + num2
    return result

ans = add(5, 7)
print("Function returned", ans)
Exam habit

When reading a function, identify three things immediately: name, parameters, and return value. Then trace the body with a small concrete input.

Looping over collections

loop_patterns.pypython
A = [1, 2, 4, 8, 16, 32, 64, 128, 256, 512, 1024]

# Loop over values
for value in A:
    print(value)

# Count and loop over values
for k, value in enumerate(A):
    print(k, value)

# Loop over positions
for k in range(len(A)):
    print(k, A[k])

# break exits immediately; continue skips to the next iteration
for value in A:
    if value == 64:
        break
    print(value)

Testing quantifiers with all / any

This is one of the most useful links between logic and code. A predicate is a statement that depends on a variable, e.g. “\(x\) contains the digit 3”.

Universal: \(\forall x \in A,\ P(x)\)

True only if \(P(x)\) is true for every element. False as soon as one counterexample is found. In Python: all(P(x) for x in A).

Existential: \(\exists x \in A,\ P(x)\)

True as soon as one witness is found. False only if \(P(x)\) is false for every element. In Python: any(P(x) for x in A).

quantifiers.pypython
def prop(x):
    return '3' in str(x)

A = {3, 13, 23, 16}

print(any(prop(x) for x in A))   # True  — at least one contains a 3
print(all(prop(x) for x in A))   # False — 16 does not
Connection

Negation swaps the quantifier: \(\neg \forall x\,P(x) \equiv \exists x\,\neg P(x)\). In code, not all(...) is the same as any(not ...). This is exactly the rule from Topic 02.

Coding styles and functions

There are several equally valid ways to write a predicate like “are sets \(A\) and \(B\) disjoint?”. You should be able to read all of them, even if you prefer one.

Single vs multiple output statements

Single output: use a result variable, then print once at the end. Multiple output: print inside the loop and use the loop's else clause (which runs only if the loop was not exited by break).

single_output.pypython
A = {2, 3, 5, 7}
B = {4, 5, 6}

result = True
for x in A:
    if x in B:
        result = False
        break

print(result)
multiple_output.pypython
A = {2, 3, 5, 7}
B = {4, 5, 6}

for x in A:
    if x in B:
        print(False)
        break
else:
    print(True)

Single vs multiple return statements

As a function, the multiple-return style is usually shorter and flatter:

single_return.pypython
def is_disjoint(A, B):
    result = True
    for x in A:
        if x in B:
            result = False
            break
    return result
multiple_return.pypython
def is_disjoint(A, B):
    for x in A:
        if x in B:
            return False
    return True
Reading tip

The multiple-return version needs no break and no loop else: return exits the function immediately. The notes use this style because it is the cleanest to read.

Set tasks in Python

The following functions implement the set concepts from Topic 03. Learn the pattern, not the exact variable names — exam code may differ.

Equality: \(A = B\)

Two sets are equal iff they have the same elements. First compare sizes (cheap), then check every element of \(A\) is in \(B\).

is_equal.pypython
def is_equal(A, B):
    if len(A) != len(B):
        return False
    return all(x in B for x in A)

Disjoint: \(A \cap B = \varnothing\)

is_disjoint.pypython
def is_disjoint(A, B):
    return all(x not in B for x in A)

Subset: \(A \subseteq B\)

is_subset.pypython
def is_subset(A, B):
    return all(x in B for x in A)

Proper subset: \(A \subset B\)

Every element of \(A\) is in \(B\), and \(B\) is strictly larger.

is_proper_subset.pypython
def is_proper_subset(A, B):
    return all(x in B for x in A) and len(A) < len(B)

Set operations

intersection.pypython
def intersection(A, B):
    return {x for x in A if x in B}
union.pypython
def union(A, B):
    C = A.copy()
    for x in B:
        C.add(x)
    return C
set_difference.pypython
def set_difference(A, B):
    return {x for x in A if x not in B}
symmetric_difference.pypython
def symmetric_difference(A, B):
    C = set()
    for x in A:
        if x not in B:
            C.add(x)
    for x in B:
        if x not in A:
            C.add(x)
    return C

Cartesian product: \(A \times B\)

Use a nested loop (or a double comprehension) to build every ordered pair.

cartesian_product.pypython
def cartesian_product(A, B):
    return {(a, b) for a in A for b in B}
Watch out

C = A does not make a copy of a set — both names point to the same object. Use C = A.copy() when you intend to build a new set starting from \(A\).

Relation tasks in Python

A relation is a set of ordered pairs. The patterns below are used again in Topic 04.

Is \(R\) a relation from \(A\) to \(B\)?

is_relation.pypython
def is_relation(R, A, B):
    for (a, b) in R:
        if a not in A:
            return False
        if b not in B:
            return False
    return True

The relation properties

PropertyMathematical conditionPython check
Reflexive\((a,a) \in R\) for all \(a \in A\)all((a,a) in R for a in A)
Symmetric\((a,b) \in R \Rightarrow (b,a) \in R\)all((b,a) in R for (a,b) in R)
Transitive\((a,b),(b,c) \in R \Rightarrow (a,c) \in R\)nested loop over pairs
Irreflexive\((a,a) \notin R\) for all \(a\)not any((a,a) in R for a in A)
Antisymmetric\((a,b),(b,a) \in R \Rightarrow a=b\)not ((b,a) in R and a != b)
Asymmetric\((a,b) \in R \Rightarrow (b,a) \notin R\)(b,a) not in R
relation_properties.pypython
def is_reflexive(R, A):
    return all((a, a) in R for a in A)

def is_symmetric(R):
    for (a, b) in R:
        if (b, a) not in R:
            return False
    return True

def is_transitive(R):
    for (a, b) in R:
        for (c, d) in R:
            if b == c and (a, d) not in R:
                return False
    return True

def is_irreflexive(R, A):
    return not any((a, a) in R for a in A)

def is_antisymmetric(R):
    for (a, b) in R:
        if (b, a) in R and a != b:
            return False
    return True

def is_asymmetric(R):
    for (a, b) in R:
        if (b, a) in R:
            return False
    return True
Transitivity, visually

The nested loop is searching for a two-hop path \(a \to b = c \to d\). Transitivity says that whenever such a path exists, the shortcut \(a \to d\) must also be present.

Surjective and injective

A relation is surjective (onto) if its image equals the target, and injective (one-to-one) if no target element has more than one incoming arrow.

surjective_injective.pypython
def is_surjective(R, B):
    image = {b for (_, b) in R}
    return image == B

def is_injective(R):
    tmp = [b for (_, b) in R]
    return len(tmp) == len(set(tmp))

The injective check uses a standard Python trick: convert a list to a set, which removes duplicates, then compare lengths.

Function task in Python

A function is a relation in which every element of \(A\) appears exactly once as a first coordinate — at most once (not a one-to-many relation) and at least once (defined on the whole source).

is_function.pypython
def is_function(R, A):
    tmp = [a for (a, _) in R]
    D = set(tmp)

    # "at most once" and "at least once"
    return len(tmp) == len(D) and D == A
Two conditions, one line

len(tmp) == len(D) checks that no first coordinate is repeated (at most once). D == A checks that every element of the source appears (at least once). Together: exactly once.

Exam guidance

What you will be asked

  • Read a Python function and state its purpose.
  • Trace code with a given input and produce the output.
  • Identify which mathematical property a function tests.
  • Recognise equivalent implementations written in a different style.

What you will not be asked

You are not expected to write large programs from scratch in the exam. The emphasis is on reading and executing code — the same skill you practise in the multiple-choice quizzes and the practical notebooks.

Common traps
  • range(1, 11) stops at 10 — Python intervals are semi-open.
  • {} is an empty dictionary, not an empty set; use set().
  • Sets are unordered, so never rely on the iteration order of a set.
  • '4' * 10 repeats a string; it does not compute \(4 \times 10\).
  • In an if/elif chain, only the first true branch runs — order your tests carefully.
  • return exits the function immediately; code after it in the same branch never runs.
