Exam format

The recent papers (2022/23 onwards) all follow the same template:

ItemDetail
Duration2 hours
Total marks100
StructureFive questions, 20 marks each. Answer all questions — there is no choice.
Marks per partMostly 1–4 marks per sub-part; one larger part (6–10 marks) per question.
Supplied materialsFormula sheet (laws of logic, set identities, counting formulas) and a Python cheat sheet, plus New Mathematics Tables and graph paper.
CalculatorStandard scientific calculator; the numbers are chosen to be doable by hand.
Timing

That is 24 minutes per question, or roughly 1.2 minutes per mark. A 2-mark part should take about 2–3 minutes. Do not spend 15 minutes on a 3-mark AP question while a 9-mark lattice-path part sits untouched. If you are stuck, write the definition or formula — method marks are awarded generously.

The five questions are not topic-pure. They are deliberately mixed so that every question touches several topics. In 2024/25, for example, Question 1 contained logic, relations, counting and truth tables. This means you cannot revise one topic and skip another: every question will contain something from at least two areas.

Recurring question recipes

Each subsection below gives the standard wording, the method that earns marks, and a model answer. The links go to the full theory in the topic pages.

Logic & truth tables

Recipe · English → propositional logic

Typical wording. “Convert the sentence into a propositional logic expression with atomic propositions.” (2–8 marks)

  1. List the atomic propositions explicitly. Use one letter per simple claim: \(I\) = “internet is stable”, \(S\) = “server is running”, \(W\) = “website is accessible”.
  2. Identify the connective words: and → \(\land\), or → \(\lor\), not → \(\neg\), if … then → \(\to\), iff → \(\leftrightarrow\).
  3. Bracket the antecedent and consequent separately. “If A and B, then C” is \((A\land B)\to C\), not \(A\land(B\to C)\).
  4. Write the final formula and, if marks allow, one sentence translating it back.
Worked answer · 2024/25 Q1(a)

Sentence. “If the internet connection is stable and the server is running, then the website will be accessible.”

Let \(I\) = “the internet connection is stable”, \(S\) = “the server is running”, \(W\) = “the website will be accessible”. Then

\[ (I \land S) \to W. \]

The marking scheme gives partial marks for failing to make the propositions atomic, so always define the letters.

Recipe · Truth table and classification

Typical wording. “Use a truth table to determine whether the proposition is a contradiction, satisfiable, or a tautology.” (5–7 marks)

  1. Count the variables \(n\); make \(2^n\) rows. Order the rows consistently: FFF, FFT, FTF, FTT, TFF, TFT, TTF, TTT.
  2. Add one column per sub-expression, innermost first: negations, then \(\land/\lor\), then \(\to\), then the whole formula.
  3. Read the final column:
    • all T → tautology;
    • all F → contradiction;
    • at least one T → satisfiable.
  4. State the conclusion in words and, if there is a mix, give one satisfying assignment.
Definitions matter

Every tautology is satisfiable; a contradiction is not. The three labels are not mutually exclusive in the way students expect. The safe sentence is: “The final column contains both T and F, so the formula is satisfiable but neither a tautology nor a contradiction.”

Recipe · Simplify with the laws of logic

Use the supplied formula sheet. The highest-yield identities are:

\[ p\to q \equiv \neg p\lor q,\qquad \neg(p\land q)\equiv \neg p\lor\neg q,\qquad p\land(q\lor r)\equiv(p\land q)\lor(p\land r). \]

Work from the outside in, and quote the law you used on each line. A 4-mark simplification usually needs three or four named steps.

Circuits & well-formed formulas

Recipe · Circuit diagram → expression

  1. Label every gate output with a temporary name (\(X_1, X_2,\ldots\)).
  2. Write the gate’s operation: AND → \(\land\), OR → \(\lor\), NOT → \(\neg\).
  3. Substitute until the output depends only on the inputs.
  4. Simplify using the laws if asked, then draw the simplified circuit left-to-right with the same gate symbols.
Worked answer · 2022/23 Q2(a)

The circuit has an AND gate producing \(X=A\land B\), and an XOR-style output \(Y=(\neg A\land B)\lor(A\land\neg B)=A\oplus B\). Then:

  • Both false? Yes — take \(A=F\), \(B=F\). Then \(X=F\) and \(Y=F\).
  • Both true? No — \(X\) is true only when both inputs are true, while \(Y\) is true only when the inputs differ. They cannot both hold.

Recipe · Well-formed formulas

Definition · Well-formed formula (WFF)

A WFF is built by these rules:

  1. Every propositional variable (\(p,q,r,\ldots\)) is a WFF.
  2. If \(\phi\) is a WFF, then \(\neg\phi\) is a WFF.
  3. If \(\phi\) and \(\psi\) are WFFs, then \((\phi\land\psi)\), \((\phi\lor\psi)\), \((\phi\to\psi)\), \((\phi\leftrightarrow\psi)\) are WFFs.
  4. Nothing else is a WFF.
Worked answer · 2023/24 Q2(a)
StringWFF?Reason
\(\lor pq\)NoA connective cannot start a formula; it needs a left operand.
\(p\neg\neg r\)NoTwo variables are juxtaposed with no connective between them.
\(p\neg\to(q\land q)\)No\(\neg\) must be followed by a formula, not by \(\to\).
\((p\land\neg q)\lor(q\neg\to q)\)NoThe sub-formula \(q\neg\to q\) has the same fault: \(\neg\) is not applied to a formula.

The exam reuses this question with different strings. Check three things: every connective has the right number of operands, negation is immediately followed by a formula, and binary connectives sit between two formulas (brackets help).

Recipe · Expression → circuit

  1. Identify the outermost connective. That is the last gate.
  2. Work inward: each \(\land\) is an AND gate, each \(\lor\) an OR gate, each \(\neg\) a NOT gate.
  3. Draw inputs on the left, output on the right. Use dots for junctions; do not draw a wire crossing as a connection without a dot.
  4. For \((A\land(B\lor C))\lor(\neg B\land\neg C)\), the last gate is OR; its left input is an AND of \(A\) with \((B\lor C)\); its right input is an AND of the two negations.

Sets & membership tables

Recipe · Set operations

For \(A\cup B\): everything in either. For \(A\cap B\): only the overlap. For \(A\setminus B\): in \(A\) but not \(B\). For \(A\oplus B\): in exactly one. For \(\bar A\): everything in \(U\) outside \(A\).

Worked answer · 2024/25 Q4(a)

\(A=\{0,1,2,3,4\}\), \(B=\{3,4,5,6\}\), \(C=\{1,4,5,6,7\}\), \(U=\{0,\ldots,9\}\).

ExpressionAnswer
\(A\cup B\)\(\{0,1,2,3,4,5,6\}\)
\(A\setminus B\)\(\{0,1,2\}\)
\(B\cap A\)\(\{3,4\}\)
\(A\oplus B\)\(\{0,1,2,5,6\}\)
\((A\cup B)\cap C\)\(\{1,4,5,6\}\)
\(\bar A\)\(\{5,6,7,8,9\}\)

Recipe · Membership table

Typical wording. “Use a membership table to determine whether \((A\setminus B)\setminus(B\setminus C)=A\setminus B\).” (5 marks)

  1. Three sets → \(2^3=8\) rows, in binary order 000 to 111.
  2. One column per side and per intermediate expression: \(A\setminus B\), \(B\setminus C\), \((A\setminus B)\setminus(B\setminus C)\), \(A\setminus B\).
  3. Compute each column using 1 = in the set, 0 = not in the set.
  4. Compare the two final columns. Identical → the identity is true.
Worked answer · 2022/23 Q5(c)

The last two columns are identical in every row, so the identity is true. Notice the simplification: \(B\setminus C\subseteq B\), and \(A\setminus B\) is disjoint from \(B\), so the second subtraction removes nothing.

Recipe · Construct sets from differences

Typical wording. “Construct \(A\) and \(B\) with \(A\setminus B=\{4,9\}\), \(B\setminus A=\{8\}\), \(A\cap B=\{1\}\).” (2 marks)

The three regions are disjoint: only-\(A\), only-\(B\), and both. Union them:

\[ A = (A\setminus B)\cup(A\cap B) = \{4,9\}\cup\{1\}=\{1,4,9\}, \]
\[ B = (B\setminus A)\cup(A\cap B) = \{8\}\cup\{1\}=\{1,8\}. \]

Check: \(A\setminus B=\{4,9\}\), \(B\setminus A=\{8\}\), \(A\cap B=\{1\}\). Always substitute back — it takes ten seconds and catches slips.

Relations & functions

Recipe · Test the relation properties

PropertyTestHow to refute
Reflexive\((a,a)\in R\) for every \(a\in A\)One missing diagonal pair.
IrreflexiveNo \((a,a)\in R\)One diagonal pair present.
Symmetric\((a,b)\in R\Rightarrow(b,a)\in R\)One pair without its reverse.
Antisymmetric\((a,b),(b,a)\in R\Rightarrow a=b\)Two distinct elements with both directions.
AsymmetricAntisymmetric and irreflexiveA diagonal pair, or a two-way pair.
Transitive\((a,b),(b,c)\in R\Rightarrow(a,c)\in R\)One chain whose shortcut is missing.
Worked answer · 2024/25 Q1(b)

\(A=\{1,2,3\}\), \(R=\{(1,1),(2,2),(3,3),(1,2)\}\).

  • Reflexive: yes — all three diagonal pairs are present.
  • Symmetric: no — \((1,2)\in R\) but \((2,1)\notin R\).
  • Transitive: yes — the only chains are \((1,1)\) then \((1,2)\), and \((1,2)\) is present; the diagonal pairs add nothing new.
  • Equivalence relation: no — it is not symmetric.
  • Antisymmetric: yes — the only two-way pairs are \((1,1),(2,2),(3,3)\), whose endpoints are equal.

The marking scheme explicitly wants a witness for each “no” and a reason for each “yes”.

Recipe · Equivalence classes

For a relation like “\(a-b\) is a multiple of \(3\)” on \(\{0,\ldots,9\}\), the classes are the congruence classes:

\[ [0]=\{0,3,6,9\},\quad [1]=\{1,4,7\},\quad [2]=\{2,5,8\}. \]

For “same number of letters when written in English”, group the numbers by word length: \(\{1,2,6\}\) (one, two, six — all 3 letters), \(\{4,5,9\}\) (four, five, nine — 4 letters), \(\{3,7,8\}\) (three, seven, eight — 5 letters). List the classes explicitly; the digraph is optional if the question says “if yes”.

Recipe · Injective, surjective, inverse

Injective (one-to-one)

Each output is hit at most once. Refute by finding two different inputs with the same output. For \(f(x)=3x-5\) on \(\mathbb{R}\), \(3a-5=3b-5\Rightarrow a=b\), so it is injective.

Surjective (onto)

Every target value is hit. For \(f:\mathbb{R}\to\mathbb{R}\), solve \(y=3x-5\) for \(x\), getting \(x=(y+5)/3\), which is real for every \(y\). So it is surjective.

An inverse exists exactly when the function is both injective and surjective (bijective). To find it, set \(y=f(x)\) and solve for \(x\), then swap the names:

\[ y=3x-5 \;\Longrightarrow\; x=\frac{y+5}{3} \;\Longrightarrow\; f^{-1}(x)=\frac{x+5}{3}. \]

Verify both directions: \(f^{-1}(f(x))=(3x-5+5)/3=x\) and \(f(f^{-1}(x))=3(x+5)/3-5=x\).

Worked answer · 2024/25 Q5(b)

\(f(\text{employee})=\text{department}\).

  • Injective? Not necessarily: if two employees work in the same department, they map to the same output.
  • Surjective? Only if every department has at least one employee. An empty department is a target with no preimage.

AP, GP & sequences

Recipe · Arithmetic progression

\[ a_n=a+(n-1)d,\qquad S_n=\frac{n}{2}\bigl(2a+(n-1)d\bigr)=\frac{n}{2}(a+\ell). \]
Worked answer · 2024/25 Q3(d)

\(a=2\), \(d=4\). The 10th term is

\[ a_{10}=2+(10-1)\cdot4=2+36=38. \]

Watch the indexing: if the question calls the first term \(a_0\), the formula is \(a+nd\). The exam usually means “10th term” = \(n=10\) with \(a_1\) first.

Worked answer · 2023/24 Q3(c)

Sequence \(7,12,17,22,27,\ldots\) with \(a=7\), \(d=5\).

  • Recursive: \(a_1=7\), \(a_n=a_{n-1}+5\) for \(n\ge2\).
  • Closed: \(a_n=7+5(n-1)=5n+2\).
  • Is 2023 a term? Solve \(5n+2=2023\Rightarrow5n=2021\Rightarrow n=404.2\notin\mathbb{N}\). No.
  • How many terms up to 437? \(5n+2=437\Rightarrow n=87\). There are 87 terms.
  • Sum: \(S_{87}=\frac{87}{2}(7+437)=\frac{87}{2}\cdot444=87\cdot222=19314\).

Recipe · Geometric progression

\[ a_n=ar^{n-1},\qquad S_n=a\frac{1-r^n}{1-r}\ (r\neq1). \]
Worked answer · 2024/25 Q2(c)

\(a=10\), \(r=0.5\). Is \(0.5\) a term?

\[ 10(0.5)^{n-1}=0.5 \;\Longrightarrow\; (0.5)^{n-1}=0.05 \;\Longrightarrow\; n-1=\log_{0.5}(0.05)\approx4.32. \]

So \(n\approx5.32\notin\mathbb{N}\): \(0.5\) is not a term. The terms are \(10,5,2.5,1.25,0.625,0.3125,\ldots\), which confirms it skips \(0.5\).

Worked answer · 2024/25 Q3(b)

A \(1024\times768\) image halves in both dimensions each step, so the pixel count multiplies by \(\tfrac12\cdot\tfrac12=\tfrac14\):

\[ a_0=786432,\qquad a_n=786432\left(\frac14\right)^n. \]

After three reductions: \(a_3=786432/64=12288\). For \(a_n<1000\): \((1/4)^n<1000/786432\approx0.00127\), so \(n>\log_4(786432/1000)\approx4.8\), giving \(n=5\).

Counting & probability

Recipe · Subsets with constraints

“How many subsets of \(S\) have cardinality \(k\) and property \(P\)?” Split the set into categories, choose from each, and multiply. Add the cases if the property is “at least” or “either”.

Worked answer · 2022/23 Q4(c)

\(S=\{a,b,c,d,e,u\}\), so 3 vowels \(\{a,e,u\}\) and 3 consonants \(\{b,c,d\}\). Subsets of size 4:

  • All: \(\binom64=15\).
  • Containing \(\{a,b,c\}\): choose 1 more from the other 3 → \(\binom31=3\).
  • At least one vowel: all 15 — a 4-element subset of a 6-element set cannot avoid all 3 vowels and still have 4 elements from only 3 consonants.
  • Exactly one vowel: choose 1 vowel from 3 and all 3 consonants → \(\binom31\binom33=3\).
Worked answer · 2024/25 Q4(b)

\(S=\{2,3,5,7,11,13,17\}\), seven elements.

  • Size 3: \(\binom73=35\).
  • All subsets: \(2^7=128\).
  • Sum 15: only \(\{2,13\}\) and \(\{3,5,7\}\). Note the empty set does not have sum 15, and \(\{2,13\}\) is a subset of size 2 — the question does not require size 3.

Recipe · Bit strings with inclusion–exclusion

Fix the forced substring first, then count free positions. For “either A or B”, use \(|A|+|B|-|A\cap B|\). For “weight \(w\)”, choose where the remaining 1s go.

Worked answer · 2024/25 Q1(c)

12-bit strings.

  • Start 1101: 4 bits fixed, 8 free → \(2^8=256\).
  • Weight 6 and start 1101: the prefix already has three 1s, so choose 3 of the remaining 8 → \(\binom83=56\).
  • Start 1101 or end 1010: \(256+256-2^4=496\). The overlap fixes both ends and leaves 4 free bits.
  • Weight 6, start 1101, end 1010: prefix has 3 ones, suffix has 2, so the middle 4 bits need exactly one 1 → \(\binom41=4\).

The common error is forgetting that the prefix/suffix may already consume some of the required weight.

Recipe · Lattice paths

A shortest path from \((0,0)\) to \((a,b)\) uses \(a\) right steps and \(b\) up steps, so there are \(\binom{a+b}{a}\) paths. Through a point \(P\): multiply the count to \(P\) by the count from \(P\) to the end. To avoid \(P\): total minus through-\(P\).

Worked answer · 2024/25 Q2(b)

To \((7,4)\): \(\binom{11}{4}=330\).

  • Through \((4,2)\): \(\binom62\binom52=15\cdot10=150\).
  • Through \((3,1)\): \(\binom41\binom73=4\cdot35=140\).
  • Through \((5,3)\): \(\binom83\binom31=56\cdot3=168\).
  • Through both: \(\binom41\binom42\binom31=4\cdot6\cdot3=72\).
  • Through either: \(140+168-72=236\).

The printed marking scheme writes \(\binom83=56\) for the paths through \((5,3)\) and concludes \(124\): it counts only the journey to \((5,3)\) and omits the final leg to \((7,4)\). Show both factors so your method is unambiguous. For “avoid \((6,5)\)” on the way from \((4,2)\) to \((9,8)\), subtract: \(\binom{11}{5}-\binom52\binom63=462-200=262\).

Recipe · Probability by counting

Probability = favourable equally-likely outcomes / total outcomes. Count both with the multiplication principle; do not guess.

Worked answer · 2022/23 Q2(c)

Eight people each choose one of two colours independently. Total outcomes: \(2^8\). Favourable: all red or all blue = 2. Probability \(=2/2^8=1/128\approx0.0078\). The marking scheme writes \(1/2^8\), treating “all the same” as one specified colour; either reading gives the same method, but check the wording — “all wearing the same colour” includes both all-red and all-blue.

Python tracing

Recipe · What does this code do?

  1. Identify the inputs and the loop bounds. For range(a, b), the last value is \(b-1\).
  2. Make a table of iterations: loop variable, key variable, output.
  3. Look for an early return or break — it changes the whole answer.
  4. Translate the effect into one sentence: “returns True iff A is a subset of B”, “prints the sum of the integers from \(-5\) to \(4\)”.
Worked answer · subset / disjoint / equality functions

The exam reuses one function with a one-word change:

Condition inside the loopMeaning
if a not in B: return FalseEvery element of \(A\) is in \(B\) → \(A\subseteq B\).
if a in B: return FalseNo element of \(A\) is in \(B\) → \(A\cap B=\varnothing\) (disjoint).
Loop ends, then return len(A)==len(B)\(A\subseteq B\) and the sizes match → \(A=B\).
Loop ends, then return {b for _,b in R}==B\(R\) is a relation from \(A\) to \(B\) and every element of \(B\) appears → \(R\) is onto/surjective.

State the quantification: “returns True iff for every \(a\in A\), \(a\in B\).” That sentence is worth the marks.

Σ and Π notation

A loop that accumulates with += is a \(\Sigma\); one that multiplies with *= is a \(\Pi\). Nested loops become nested symbols, with the outer loop on the left.

Worked answer · 2024/25 Q3(c)
nested.pypython
var_a = 0
for k in range(1, 3):
    var_b = 1
    for j in range(k):
        var_b *= (j + k) ** 2
    var_a += var_b
print(f"{var_a = }")

The outer sum is over \(k=1,2\). The inner product runs \(j=0,\ldots,k-1\):

\[ \sum_{k=1}^{2}\ \prod_{j=0}^{k-1}(j+k)^2. \]

Evaluate: for \(k=1\), \(\prod_{j=0}^{0}(j+1)^2=1\). For \(k=2\), \(\prod_{j=0}^{1}(j+2)^2=2^2\cdot3^2=36\). Total \(1+36=37\).

Range → limits

range(1, 3) is \(k=1,2\) (upper limit 2). range(k) is \(j=0,\ldots,k-1\). If the code uses range(0, n+1), the sum runs to \(n\), not \(n+1\). Write the limits first, then the summand.

Graphs

The full theory is on the Graphs & Networks page. The exam asks four things:

Recipe · Degree sequence / simple graph?

  1. Sort descending.
  2. Check the sum is even and each degree \(\le n-1\).
  3. Apply Havel–Hakimi: remove the largest degree \(d\), subtract 1 from the next \(d\) entries, repeat.
  4. A negative entry ⇒ no simple graph. All zeros ⇒ draw it.
Worked answer · 2024/25 Q5(a)

\((3,3,5,5,5,5)\to(5,5,5,5,3,3)\to(4,4,4,2,2)\to(3,3,1,1)\to(2,0,0)\to(-1,-1)\). No simple graph exists.

Contrast the 2024/25 repeat: the drawn graph has degree sequence \((3,3,4,4,4,4)\), which is simple (no loops or parallel edges) and has girth 3 (a triangle such as \(A\!-\!C\!-\!D\!-\!A\)).

Recipe · Adjacency matrix

Simple? All entries 0 or 1, diagonal all 0. A 2 means parallel edges; a diagonal 1 means a loop. Degree sequence? Row sums, sorted. Edges? Sum of degrees ÷ 2.

Proof by cases

Typical wording. “Prove that \(n(n^2+5)\) is divisible by 3 for every positive integer \(n\). (Hint: proof by cases.)” (7 marks)

  1. Every integer has remainder 0, 1, or 2 modulo 3, so write \(n=3k\), \(3k+1\), or \(3k+2\).
  2. Substitute each case and factor out a 3.
  3. Conclude that the expression is \(3\times\) (an integer) in every case, hence divisible by 3.
Worked answer · 2022/23 Q5(b)
Case\(n^2+5\)\(n(n^2+5)\)
\(n=3k\)\(9k^2+5\)\(3k(9k^2+5)\) — multiple of 3
\(n=3k+1\)\(9k^2+6k+6=3(3k^2+2k+2)\)\(3(3k+1)(3k^2+2k+2)\) — multiple of 3
\(n=3k+2\)\(9k^2+12k+9=3(3k^2+4k+3)\)\(3(3k+2)(3k^2+4k+3)\) — multiple of 3

All three cases are exhausted, so the statement holds for every positive integer \(n\). The marks are for the case split, the algebra in each case, and the concluding sentence.

Revision plan

A four-pass plan for the final two weeks. Each pass is about 2–3 hours.

Pass 1 · Learn the recipes

  1. Read the logic, sets and relations sections of this guide.
  2. Cover each worked answer and redo it on paper.
  3. Make a one-page “method card” for each of the twelve recipes.
  4. Memorise the formula sheet — especially the AP/GP and counting formulas.

Pass 2 · Topic drills

  1. Do the tutorial-sheet questions for graphs and enumeration.
  2. Redo every truth table from 2022/23–2024/25 without looking.
  3. Time yourself: 10 minutes for a 6-mark truth table.
  4. Mark against the official solutions; note every lost mark and why.

Pass 3 · Full papers

  1. Sit the 2024/25 final in 2 hours, no notes.
  2. Mark it honestly. Anything below 70% identifies a topic to revisit.
  3. Repeat with 2023/24, then 2022/23.
  4. Keep an error log: topic, question, mistake, fix.

Pass 4 · Error log only

  1. Do not reread everything. Work only from your error log.
  2. Re-attempt the exact questions you got wrong.
  3. Recite the definitions aloud: degree, girth, Eulerian, equivalence relation, injective.
  4. Sleep. Cramming new material the night before costs more than it gains.

In the exam room

  • Read all five questions first (2 minutes). Note which parts are quick wins.
  • Do the quick wins first. Set operations, cardinality, function evaluation, girth, AP/GP nth term: these are 1–3 marks each and build confidence.
  • Show the method. “Row sums are … so the degree sequence is …” earns more than the bare sequence.
  • Write definitions. If a question says “justify”, the definition is the justification.
  • Draw the truth table fully. A final column without intermediate columns loses parsing marks.
  • Label graph diagrams and mark the cycle you are using for girth.
  • Check the sum of degrees is even before claiming a graph exists.
  • Substitute back into set-construction and inverse-function answers.
  • Watch the index in AP/GP questions: is the first term \(a_0\) or \(a_1\)?
  • If stuck, start the definition. Partial marks are real; a blank page scores zero.
  • Leave 5 minutes to check arithmetic and that every sub-part has an answer.
The 60% rule

Most of the paper is routine application of a dozen methods. If you can do every worked answer on this page from memory, you are already at a comfortable pass. The remaining marks come from careful justification and arithmetic, not from exotic theory.
